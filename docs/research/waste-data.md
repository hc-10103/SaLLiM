# 지역별 배출 요일 데이터

## 출처와 범위

- 원본: [행정안전부 생활쓰레기배출정보 파일](https://www.data.go.kr/data/15075534/fileData.do)의 **전국 파일 다운로드**. 원본 다운로드 화면은 <https://file.localdata.go.kr/file/household_waste_info/info>.
- 제공 내용: 시도·시군구·관리구역·대상지역별 일반쓰레기, 음식물쓰레기, 재활용품의 배출 요일·시간·방법·미수거일·담당부서·데이터 기준일.
- 2026-11-07에 내려받은 CSV를 `data/waste_areas.json`으로 변환했다. 10,187개 관리구역, 222개 시군구가 포함됐다. 원본의 각 행은 서로 다른 관리번호로 유지했다.
- 공공데이터포털의 [조회 API](https://www.data.go.kr/data/15155080/openapi.do)도 있지만 활용신청과 서버에 보관할 인증키가 필요하다. 이 버전은 키 없이 공식 CSV를 사용한다.

## 갱신 방법

1. 레포 루트에서 `python3 server/scripts/update_waste_data.py --download`를 실행한다. 서버가 공식 CSV 다운로드 주소에 접속할 수 없다면 원본 화면에서 **전국 파일 다운로드**를 누르고 `python3 server/scripts/update_waste_data.py ~/Downloads/생활쓰레기배출정보.csv`를 실행한다.
2. `cd server && .venv/bin/python -m pytest -q`로 확인한다. 변경된 지역·기준일을 검토하고 서버를 재시작한다.

CSV는 CP949로 읽는다. 앱용 JSON에는 각 행의 관리번호, 지역, 배출 요일·시간·방법, 자료 기준일만 남긴다. 서버는 시작할 때 데이터의 필드와 관리번호 중복 여부를 확인한다.

## 앱과 API

- `GET /waste-areas?query=서울%20마포구`: 이름에 맞는 관리구역 최대 30개와 전체 검색 건수.
- `GET /waste-areas/{관리번호}`: 선택한 관리구역의 세 종류 배출 요일·시간·방법, 미수거일, 기준일과 출처.
- 앱 설정에서 시군구를 검색하고, 결과가 여러 개면 동·관리구역을 더 좁혀 선택한다. 선택한 관리번호를 기기에 저장한다. 사진·채팅의 품목별 분리배출 방법은 기존 `region_id` 규칙을 유지하고, 공식 배출 요일은 홈의 별도 카드로 보여 준다.

## 표시할 때 주의할 점

- 원본의 `데이터기준일자`는 지역마다 다르고, 일부는 오래되었다. 앱에서 기준일을 그대로 보여 준다.
- 같은 구 안에서도 동·관리구역별로 다른 요일이 있다. 검색 결과가 여러 개인 구를 하나로 합치지 않는다.
- 원본은 일반 재활용품 요일을 제공한다. 투명페트병·비닐 등 **품목별 요일제**는 별도 구청 공지 확인 전까지 이 데이터에서 추론하지 않는다.
- 공동주택, 공휴일, 명절의 실제 일정은 지자체·단지 안내문이 우선이다. `미수거일` 원문도 함께 보여 준다.
